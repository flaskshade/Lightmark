# Markdown reading sample

The table below exercises aligned columns and inline code.

| Food nutrient score | Customer source label | Internal tier | Base signal |
|---:|---|---:|---:|
| `8.0–10.0` | Excellent source | `leading` | 3 |
| `6.0–7.99` | Good source | `strong` | 2 |
| `4.0–5.99` | Moderate source | `meaningful` | 1 |
| `< 4.0` | Limited source | `limited` | 0 |
